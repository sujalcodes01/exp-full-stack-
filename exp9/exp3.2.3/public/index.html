Cloud Deployment Lab

AWS Deployment with Load Balancing

This sample full-stack app is deployed on ECS behind an Application Load Balancer with auto-scaling and CI/CD automation.

Infrastructure

  • VPC across 2 availability zones
  • Public ALB + private ECS tasks
  • Auto Scaling Group for ECS capacity
  • Terraform-managed infrastructure

Deployment Flow

  1. Push to GitHub
  2. CodePipeline triggers CodeBuild
  3. Docker image is pushed to ECR
  4. ECS service rolls out the new version
