# Login Form with React State Management

This project demonstrates a secure login form using React state management for client-side validation.

## Features

- Responsive login UI using Material UI
- Form validation with React Hook Form
- Loading spinner on submit
- Success and error alerts
- Controlled inputs

## Requirements

- React 18+
- React Hook Form 7.49+
- Material UI 5.14+
- Node.js and npm

## Installation

1. Clone or download the project.
2. Navigate to the project directory: `cd login-form`
3. Install dependencies: `npm install`

## Usage

1. Start the development server: `npm start`
2. Open [http://localhost:3000](http://localhost:3000) in your browser.
3. Enter email: `test@test.com` and password: `password` for successful login.
4. Try invalid credentials to see error handling.

## Testing

- Email validation: Must be a valid email format.
- Password validation: At least 6 characters.
- Submit button shows loading spinner during simulation.
- Alerts display success or error messages.

## Build for Production

Run `npm run build` to create a production build.
